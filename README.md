# VaR Correlation Matrix

Interactive VaR and correlation matrix dashboard built with React + Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy on Vercel

1. Import this repository in Vercel.
2. Framework preset: `Vite`.
3. Build command: `npm run build`.
4. Output directory: `dist`.

The repository includes `vercel.json` with SPA rewrite support.
